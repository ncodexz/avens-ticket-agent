# src (entorno Databricks)

Adaptadores y app para Databricks: lectura de tablas con el SQL warehouse, modelos de `system.ai`,
secretos con `dbutils.secrets.get`, y la app visual que se despliega como App de Databricks.

Al integrar con el repositorio de Alenia se copian `src` y `core` hacia una rama de ese repositorio,
nunca al reves. Debe respetar su estructura (app.py en la raiz y requirements con versiones `==`).
